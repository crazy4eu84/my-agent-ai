# 나의 AI 비서 산초(Sancho) 13단계 통합 청사진 (Blueprint)

> **"외부 프로그램을 따로 설치하지 않고 순수 Node.js만으로, 내 PC의 AI 두뇌(Claude Code)와 로컬 데이터가 유기적으로 연결되는 13단계 개인 업무 비서"**

## 1. 개요 및 3대 철칙

- **이름**: 나의 AI 비서 산초 (Sancho)
- **정체성**: 내 컴퓨터(PC) 안에서만 혼자 돌아가는 개인 업무 비서이자 화면(웹 대시보드)입니다.
- **접속 방식**: 브라우저(크롬/엣지)를 켜고 비밀번호를 입력해 로그인하여 사용합니다.
- **구조도(그림) 확인**: [docs/architecture.html](file:///c:/Users/USER/Downloads/Sancho-Test/docs/architecture.html) (Archify로 생성된 13단계 상호 연동 인터랙티브 HTML 다이어그램)

### 3대 철칙 (절대 안 할 것)
1. **메일 자동 발송 금지**: AI가 공손한 메일 초안을 써주지만, 사용자가 직접 눈으로 보고 [발송]을 누르기 전에는 절대로 혼자 보내지 않습니다.
2. **확인 없는 파일 삭제 금지**: 디스크 공간 확보나 정리 작업 시에도 반드시 "이 파일을 지울까요?" 확인 팝업을 띄우고 승인을 받습니다.
3. **외부 유출 원천 차단**: 모든 자료와 대화는 내 컴퓨터 [`data/`](file:///c:/Users/USER/Downloads/Sancho-Test/data/) 폴더 안에만 머물며 외부로 나가지 않습니다.

## 2. 두뇌 작동 방식 및 기능 연결 구조

```
[ 웹 브라우저 (13개 메뉴) ]
       │  ▲
       ▼  │ (화면 요청 / JSON 통신)
[ server.js 코어 엔진 (순수 Node.js) ] ── (안전 검증) ──> [ 3대 안전장치 ]
       │  ▲
       ▼  │ (child_process 표준입출력 / 추가 비용 0원)
[ 로컬 AI 두뇌 (Claude Code) ] 
       │  ▲
       ▼  │ (기억 및 데이터 참조)
[ data/ 로컬 저장소 ]
  ├── *.json (일정, WBS, 프로젝트, 목표, 공수, 설정)
  └── notes/ & memory.md (회의록, 지식노트, AI 장기 기억)
```

- **두뇌 연결 방식**: 별도의 비싼 개발자 API 키를 사지 않고, 내 PC에 이미 로그인되어 있는 **Claude Code CLI** 프로세스를 `server.js`가 뒤에서 호출(`child_process`)하여 답변을 받아옵니다.
- **기억 연동**: AI는 매 질문마다 [`data/`](file:///c:/Users/USER/Downloads/Sancho-Test/data/) 폴더의 과거 대화 기억(`memory.md`)과 업무 파일들을 먼저 읽고 답변하므로, 나를 가장 잘 아는 비서처럼 행동합니다.
- **기능 간의 연쇄 흐름 (시너지)**:
  1. **회의록(9단계)**에서 회의 내용을 정리하면 $\rightarrow$ AI가 '할 일'을 뽑아 **WBS(5단계)**와 **일정(3단계)**에 자동 추가
  2. **WBS(5단계)**의 일감이 완료되면 $\rightarrow$ **목표(11단계)** 달성률 게이지가 자동으로 올라감
  3. **공수(12단계)**에서 오늘 일한 시간을 적으면 $\rightarrow$ WBS 일감별 투입 시간 분석 및 비효율 조언
  4. 아침에 출근해서 **대시보드(2단계)**를 켜면 $\rightarrow$ 오늘 일정, 마감 직전 WBS 일감, 회의 일정을 AI가 한눈에 요약 브리핑

## 3. 13단계 순차 제작 로드맵

규칙에 따라 **한 번에 한 단계씩** 만들고, 단계마다 **`node selftest.js` 검증**과 **한국어 커밋/태그 푸시**를 진행합니다.

| 단계 | 메뉴 이름 | 무엇을 만드나요? | 어떻게 연결되고 사용되나요? |
| :---: | :--- | :--- | :--- |
| **1단계** | **설정 & 로그인 · 두뇌** | • 비밀번호 기반 로컬 로그인 화면<br>• PC의 Claude Code 두뇌 연결 브릿지<br>• 이전 대화를 기억하는 마크다운 메모리 | 전체 비서의 **기반(엔진)**이 되며, 이후 모든 메뉴에서 이 두뇌를 사용합니다. |
| **2단계** | **대시보드 (홈)** | • 오늘 하루 업무/일정 한눈에 보기<br>• 화면 중앙의 상시 실시간 AI 채팅창 | 일정, WBS, 프로젝트의 최신 상태를 모아서 출근 시 첫 브리핑을 해줍니다. |
| **3단계** | **일정 (캘린더)** | • 날짜별 일정/약속 등록 및 캘린더 뷰<br>• 중요한 업무 D-day 카운트다운 | 대시보드에 오늘 일정을 전달하고, 6단계 예약 알림과 연동됩니다. |
| **4단계** | **프로젝트** | • 굵직한 프로젝트 카드 관리 (칸반 보드 형태)<br>• 진행 중 / 완료 / 보류 상태 분류 | 프로젝트마다 아래에 5단계의 세부 일감(WBS)들이 매달립니다. |
| **5단계** | **WBS (작업분할표)** | • 프로젝트를 하루 단위의 작은 일감으로 세분화<br>• 계층형 트리 및 진행률(%) 자동 계산 | 9단계 회의록에서 추출된 할 일이 여기 들어가며, 11단계 목표 달성률에 직결됩니다. |
| **6단계** | **예약 & 알림** | • 정해진 시간마다 리마인더 알림<br>• 아침 9시 출근 데일리 브리핑 예약<br>• PC 정기 점검 스케줄러 | 일정과 WBS의 마감일을 감시하여 브라우저에 팝업 알림을 띄웁니다. |
| **7단계** | **메일** | • 공손하고 격식 있는 비즈니스 메일 초안 작성<br>• 긴 업무 메일 본문 핵심 3줄 요약 | *(철칙 준수)* AI는 초안만 써주고, 발송은 사용자가 직접 승인/발송합니다. |
| **8단계** | **메신저** | • 사내 메신저(카톡/슬랙 등) 상황별 답변 추천<br>• 부드러운 거절, 빠른 진척 보고 문구 생성 | 회의록이나 지식노트의 내용을 참고해 적절한 답변 문구를 즉시 만들어 줍니다. |
| **9단계** | **회의록** | • 두서없는 회의 내용 입력 시 핵심 3줄 요약<br>• 참석자별 '해야 할 일(Action Item)' 추출 | 추출된 할 일을 클릭 한 번으로 3단계 일정이나 5단계 WBS로 전송합니다. |
| **10단계** | **결재** | • 품의서, 기안서, 지출결의서 서식 자동 완성<br>• 상신 사유 및 기대 효과 문구 작성 지원 | 프로젝트/WBS의 예산 및 일정 데이터와 연동되어 보고서 작성을 돕습니다. |
| **11단계** | **목표 (OKR/KPI)** | • 이번 달/분기 달성할 핵심 목표 등록<br>• 목표 달성률 프로그레스 바 표시 | 4단계 프로젝트와 5단계 WBS의 완료율을 자동으로 집계해 달성률을 보여줍니다. |
| **12단계** | **공수 (시간 분석)** | • 오늘 어떤 일에 몇 시간을 썼는지 타임테이블 입력<br>• 낭비된 시간(병목 현상) 분석 및 AI 조언 | 5단계 WBS 일감마다 사용된 시간을 연결하여 업무 효율성을 분석합니다. |
| **13단계** | **지식노트 & 워크플로** | • 업무 매뉴얼, 노하우, 웹 링크 보관소(위키)<br>• 매일 반복하는 작업들을 버튼 하나로 순차 실행 | AI가 지식노트를 뒤져서 업무 질문에 답하고, 반복 업무를 한 번에 끝냅니다. |

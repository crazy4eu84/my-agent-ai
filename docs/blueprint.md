# 나의 AI 비서 산초(Sancho) 플랫폼 엔터프라이즈 청사진 (Blueprint)

> **"Antigravity AI 두뇌를 웹으로 완전 복제(파일 생성, 코드 자가수정, MCP·스킬, 영상/오피스 제작)하고, MS Project급 WBS와 전자서명 결재 및 다중 사용자 협업까지 품은 완전한 로컬 비서 플랫폼"**

---

## 1. 개요 및 비전

- **이름**: 나의 AI 비서 산초 (Sancho Platform)
- **최종 목표**: 단순한 채팅봇이 아니라, **현재 나와 대화하고 있는 Antigravity의 강력한 능력(파일 생성·편집, 시스템 명령 실행, 코드 자가수정, MCP 커넥터, 맞춤형 스킬, 문서/영상 제작 등)을 웹 화면에서 똑같이 부리고 실행하는 완성형 플랫폼**입니다.
- **다중 사용자 & 협업 확장**: 나 혼자 쓰는 비서에 그치지 않고, 팀원이나 외부 협력자도 함께 들어와 메신저로 소통하고, 결재 문서를 올리고, 전자서명을 날인할 수 있는 모던 엔터프라이즈 시스템으로 진화합니다.
- **시각 구조도 확인**: [docs/architecture.html](file:///c:/Users/USER/Downloads/Sancho-Test/docs/architecture.html) (Archify로 생성된 엔터프라이즈 아키텍처 다이어그램)

## 2. 핵심 아키텍처 및 두뇌 복제 원리

```
[ 브라우저 UI (대시보드·WBS·메일·메신저·결재 등 13개 화면) ]
         │ ▲ (실시간 대화 / WebSocket / HTTP)
         ▼ │
[ server.js 플랫폼 코어 (순수 Node.js, 다중 사용자 세션) ]
   ├── [ 전자서명 & 결재 엔진 (서명 이미지 날인, 직인 합성, 감사로그) ]
   └── [ 3대 안전장치 (파일 삭제 전 확인 팝업, 중요 메일 승인 발송, 외부 격리) ]
         │ ▲
         ▼ │ (Antigravity Bridge / 표준 입출력 및 Agent API)
[ Antigravity 복제 두뇌 (나만의 로컬 슈퍼 AI) ]
   ├── [ 실행 능력 ]: 파일 생성 및 편집 (HWP 한글, 워드, 엑셀, PPT, 영상 제작 스크립트)
   ├── [ 자가 수정 ]: 비서 플랫폼의 코드 버그나 기능을 산초가 스스로 고치고 개선
   ├── [ MCP & 커넥터 허브 ]: Gmail, Google Drive, 카카오톡/슬랙, 외부 DB 연동
   └── [ 스킬(Skills) 엔진 ]: 나만의 반복 업무 스킬을 정의하고 버튼 하나로 실행
         │ ▲
         ▼ │
[ data/ 안전 저장소 (Git 제외) ]
   ├── *.json (WBS 계층 트리, 프로젝트, 결재 기안서, 일정)
   ├── signatures/ (사용자별 등록된 전자서명 이미지)
   └── notes/ & memory.md (회의록 STT 텍스트, 위키, AI 장기 기억)
```

## 3. 고도화된 13단계 상세 기능 명세서

### 1단계: 설정 & 로그인 · Antigravity 두뇌 복제
- **다중 사용자 로그인**: 비밀번호 `scrypt` 암호화 및 30일 HttpOnly 세션 쿠키, 10회 실패 시 10분 잠금.
- **Antigravity 두뇌 직결**: 대화창에서 AI가 직접 **파일 생성**, **코드 자가수정**, **시스템 도구 호출**을 수행할 수 있도록 파이프라인 구성.
- **MCP & 커넥터 허브**: Google Drive, Gmail, 브라우저 제어 커넥터 장착 기반 마련.
- **장기 기억 장치**: [`data/memory.md`](file:///c:/Users/USER/Downloads/Sancho-Test/data/memory.md)를 통해 사용자의 지시와 노하우를 영구 보관.

### 2단계: 대시보드 (홈) & 아침 출근 브리핑
- **출근 자동 브리핑**: 아침에 접속하면 **"읽지 않은 중요 메일 요약"**과 **"오늘 마감해야 할 WBS 일감"**을 자동으로 묶어서 AI가 오늘 할 일 3가지를 음성/텍스트로 브리핑.
- **중앙 슈퍼 AI 채팅창**: 파일 생성/수정, 코드 실행, 영상 스크립트 제작을 지시하는 메인 작업대.

### 3단계: 일정 (스마트 캘린더)
- **월간 / 주간 / 일간 캘린더**: 드래그 앤 드롭으로 스케줄 조정.
- **메일 연동 자동 등록**: 수신된 메일에서 "OO일 OO시 미팅" 일정이 발견되면 산초가 캘린더에 자동 입력 제안.
- **D-day 카운트다운**: 주요 프로젝트 및 회의 디데이 실시간 추적.

### 4단계: 프로젝트 (프로젝트 허브)
- **칸반 카드 뷰**: 기획 / 진행 중 / 검토 / 완료 상태를 카드로 한눈에 이동.
- **프로젝트 룸**: 프로젝트마다 연관된 WBS, 결재 문서, 회의록을 한곳에 자동 집계.

### 5단계: WBS (MS Project급 계층 간트차트)
- **대 / 중 / 소 계층형 트리**: 복잡한 업무를 대분류 $\rightarrow$ 중분류 $\rightarrow$ 소일감으로 체계화.
- **인터랙티브 간트차트 (Gantt Chart)**: 작업별 시작일과 완료일 타임라인 시각화, 지연 일감 붉은색 표시.
- **진척률 자동 계산**: 하위 소일감들의 완료 상태에 따라 상위 프로젝트 진행률(%) 자동 승격.
- **유기적 연계**: 9단계 회의록에서 추출된 액션 아이템이 클릭 한 번으로 WBS 특정 단락에 일감으로 추가됨.

### 6단계: 예약 & 알림
- **크론형 정기 스케줄러**: 아침 9시 데일리 브리핑, 오후 6시 퇴근 일일 업무일지 자동 요약.
- **브라우저 푸시 알림**: 마감 1시간 전, 미팅 10분 전 화면 우측 상단 팝업 알림.

### 7단계: 메일 (지능형 메일 센터)
- **메일 수신 및 3줄 요약**: 업무 메일에서 답장해야 할 핵심 질문만 요약 추출.
- **공손한 비즈니스 초안 작성**: 원클릭으로 정중하고 격식 있는 회신문 작성.
- **메일 자동화 파이프라인**: 사용자 최종 승인 하에 안전하게 발송 처리.

### 8단계: 메신저 (사내 협업 & 원격 제어)
- **독립형 웹 메신저 탑재**: 팀원이나 외부 협업자가 산초에 로그인하여 실시간 대화 가능.
- **외부 메신저 연계 (카카오톡 / 슬랙)**: 외부 이동 중에도 카톡/슬랙 봇을 통해 산초에게 "오늘 일정 뭐야?", "그 파일 만들어줘"라고 지시하고 결과 수신.

### 9단계: 회의록 (실시간 음성 STT & 문서화)
- **웹 브라우저 마이크 실시간 녹음**: Web Audio API를 활용한 음성 입력.
- **실시간 텍스트 변환 (STT) & 회의 요약**: 두서없는 회의 대화를 일목요약하고 참석자별 '할 일(Action Item)' 자동 추출.
- **즉시 연동**: 추출된 할 일을 클릭 한 번으로 3단계 일정 및 5단계 WBS로 전송.

### 10단계: 결재 (전자서명 & 다중 사용자 품의)
- **표준 서식 자동 완성**: 품의서, 기안서, 지출결의서 양식을 AI가 업무 맥락에 맞춰 자동 작성.
- **전자서명 등록 시스템**: 내 서명(도장/사인 이미지)을 등록해두고, 결재 승인 시 문서 하단에 서명 자동 날인.
- **다중 결재선**: 기안자 작성 $\rightarrow$ 검토자 승인 $\rightarrow$ 최종 관리자 결재 프로세스 지원.

### 11단계: 목표 (OKR / KPI 트래커)
- **핵심 목표 달성률 게이지**: 분기/월별 핵심 목표 설정.
- **WBS 자동 집계**: 연관된 WBS 세부 일감들의 완료율을 합산하여 목표 달성률 실시간 반영.

### 12단계: 공수 (시간 자원 분석기)
- **업무별 투입 시간 기록**: WBS 일감마다 몇 시간 일했는지 타임테이블 입력.
- **병목 현상 진단**: 시간 낭비가 심한 업무를 AI가 찾아내고 자동화 솔루션 제안.

### 13단계: 지식노트 & 스킬 워크플로 (자가 진화)
- **오피스 문서 자동 생성**: HWP(한글), Word(docx), Excel(xlsx), PPT(pptx) 파일을 대화만으로 생성 및 다운로드.
- **영상/미디어 생성 파이프라인**: 텍스트 대본을 주면 음성(TTS)과 영상 생성 모델을 엮어 미디어 제작.
- **자가 수정 (Self-Healing)**: 비서 플랫폼에 필요한 기능이나 버그를 대화창에서 산초에게 "이 화면에 기능 추가해줘"라고 지시하면 산초가 스스로 자기 코드를 수정하고 핫 리로드.

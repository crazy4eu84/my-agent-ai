# 나의 AI 비서(my-agent) Sancho 청사진 (Blueprint)

> **"외부 패키지 없이 순수 Node.js만으로, 내 PC의 AI 두뇌와 로컬 파일로 구동되는 안전한 독립형 업무 비서"**

---

## 1. 개요 및 핵심 원칙

- **이름**: 나의 AI 비서 Sancho (산초)
- **정체성**: 내 컴퓨터(로컬 PC)에서 단독으로 실행되는 개인 AI 비서 겸 전용 업무 대시보드(웹 화면)입니다.
- **접속 방식**: 브라우저(Chrome/Edge 등)를 열어 비밀번호를 입력하고 로그인해서 사용합니다.
- **아키텍처 시각화 다이어그램**: [docs/sancho-architecture.html](file:///c:/Users/USER/Downloads/Sancho-Test/docs/sancho-architecture.html) (Archify로 생성된 독립형 인터랙티브 HTML 구조도)

### 3대 철칙 (절대 안 할 것)
1. **메일 자동 발송 금지**: AI가 내용을 작성할 수는 있지만, 사용자가 화면에서 직접 [발송] 버튼을 누르기 전에는 절대 혼자 보내지 않습니다.
2. **확인 없는 파일 삭제 금지**: 디스크 공간 확보나 정리 작업 시에도 반드시 "이 파일을 지울까요?" 확인 팝업을 띄우고 승인을 받습니다.
3. **외부 유출 절대 금지**: 모든 데이터는 내 컴퓨터의 로컬 환경 안에서만 머물며, 외부 서버로 문서를 무단 전송하지 않습니다.

## 2. 기술 스택 및 구조 (Tech Stack)

### ① 두뇌 (AI Brain)
- **방식**: 별도의 유료 API 키(비용 발생하는 외부 키)를 사지 않습니다.
- **연동**: 이미 내 컴퓨터에 로그인되어 구독 중인 **Claude Code / Google Antigravity / GPT CLI** 프로세스를 백그라운드 브릿지(`child_process`)로 호출하여 그대로 활용합니다.

### ② 백엔드 (Server)
- **외부 패키지(npm) 0개**: `npm install express` 같은 외부 라이브러리를 일절 쓰지 않습니다.
- **순수 Node.js 내장 모듈만 사용**:
  - `http`: 웹 서버 구축 및 API 통신
  - `fs`: 파일 읽기/쓰기 (로컬 데이터 저장)
  - `path`: 안전한 파일 경로 처리
  - `crypto`: 비밀번호 암호화 및 안전한 로그인 토큰(세션) 생성
  - `child_process`: 로컬 AI 도구 실행 및 시스템 명령 전달

### ③ 데이터 저장소 (Data Layer)
- 무거운 데이터베이스(MySQL, MongoDB 등) 프로그램을 별도로 깔지 않습니다.
- 모든 자료는 프로젝트 내 [`data/`](file:///c:/Users/USER/Downloads/Sancho-Test/data/) 폴더 안에 **JSON(데이터 파일)**과 **Markdown(텍스트/기억 파일)** 형태로 영구 보관합니다.
- [`.gitignore`](file:///c:/Users/USER/Downloads/Sancho-Test/.gitignore)에 의해 `data/` 폴더는 GitHub에 절대 올라가지 않아 사생활과 개인 업무 내용이 완벽히 보호됩니다.

## 3. 화면 구성 (User Interface)

웹 브라우저로 접속하면 나타나는 직관적인 2단 레이아웃입니다:

### 1) 왼쪽 내비게이션 메뉴 (총 13개)
1. **대시보드** (전체 현황 및 AI 비서 홈)
2. **일정** (캘린더 및 리마인더)
3. **프로젝트** (업무 진행 현황)
4. **WBS (작업분할구조도, Work Breakdown Structure)**: 큰 프로젝트를 작은 세부 일감으로 쪼개서 관리하는 표
5. **메일** (초안 작성 및 수신 메일 요약)
6. **메신저** (사내/업무 메신저 문구 다듬기)
7. **회의록** (회의 내용 요약 및 할 일 추출)
8. **결재** (기안서 작성 및 결재 진행 상태)
9. **목표** (OKR / KPI 등 달성률 트래킹)
10. **공수 (업무 투입 시간 계산)**: 어떤 업무에 몇 시간 썼는지 기록하고 비효율 분석
11. **지식노트** (업무 매뉴얼, 링크, 노하우 저장소)
12. **워크플로 (업무 흐름도)**: 반복 작업의 순서를 지정해 순차 실행
13. **설정** (로그인 계정, 테마, 두뇌 모델 선택)

### 2) 중앙 메인 화면 (대시보드 + AI 채팅)
- 화면 중앙의 핵심 영역에 **실시간 AI 채팅창**이 상시 배치됩니다.
- "오늘 할 일 브리핑해 줘", "특강 자료 목차 짜줘", "SJ-CFD 연산 상태 확인해 줘" 등을 대화하듯 지시할 수 있습니다.
- 상단에는 오늘 일정, 긴급 일감, 최근 회의 요약 카드가 위젯 형태로 표시됩니다.

## 4. 로드맵 10편 (단계별 제작 여정)

각 편이 완성될 때마다 안전하게 Git 커밋과 태그를 붙여 GitHub에 자동 백업합니다.

| 편 (Phase) | 제목 | 주요 개발 내용 및 기능 |
| :---: | :--- | :--- |
| **제1편** | **로그인 · 채팅 · 두뇌 · 기억** | • 내장 HTTP 서버 및 단일 로그인 화면<br>• 로컬 AI 두뇌(`child_process`) 연결<br>• 기본 AI 채팅 및 이전 대화를 기억하는 마크다운 메모리 |
| **제2편** | **대시보드 · 일정** | • 왼쪽 13개 사이드 메뉴 레이아웃<br>• 캘린더 기반 일정 추가/조회/마감일 카운트다운<br>• 오늘 업무 한눈에 보기 대시보드 위젯 |
| **제3편** | **프로젝트 · WBS** | • 프로젝트 관리 카드뷰(칸반 보드)<br>• WBS(일감 세분화 표) 계층형 트리 및 진척도 게이지 |
| **제4편** | **예약 · 알림** | • 타이머 및 정기 스케줄러(내장 모듈 기반)<br>• 마감 직전 브라우저 팝업 알림<br>• 아침 9시 출근 데일리 브리핑 자동 출력 |
| **제5편** | **메일 · 문서** | • 메일 템플릿 기반 AI 초안 생성기<br>• 다운로드된 문서/텍스트 요약 및 서식 자동 변환 |
| **제6편** | **메신저 · 회의록** | • 음성/텍스트 회의록 입력 시 3줄 요약 및 액션 아이템 추출<br>• 상황별 공손한/단호한 업무 메신저 답변 생성 |

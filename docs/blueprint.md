# 나의 AI 비서 산초(Sancho) 청사진

> **"외부 프로그램을 따로 깔지 않고 오직 내 컴퓨터의 기본 기능만으로, 이미 결제된 내 AI 두뇌와 안전한 로컬 파일을 엮어 만든 독립형 업무 비서"**

---

## 1. 개요 및 핵심 원칙

- **이름**: 나의 AI 비서 산초 (Sancho)
- **정체성**: 외부 클라우드 서버가 아니라 내 컴퓨터(PC) 안에서만 혼자 돌아가는 개인 업무 비서이자 화면(웹 대시보드)입니다.
- **사용 방법**: 크롬이나 엣지 같은 웹 브라우저를 켜고 비밀번호를 입력해 로그인해서 사용합니다.
- **한글 구조도(그림) 보기**: [docs/sancho-architecture.html](file:///c:/Users/USER/Downloads/Sancho-Test/docs/sancho-architecture.html)  
  *(Archify로 제작된 움직이는 한글 인터랙티브 구조도입니다. 브라우저로 열면 한글로 모든 구조를 그림으로 볼 수 있습니다.)*

---

### 3대 철칙 (산초가 절대 하지 않는 것)
1. **메일 알아서 보내기 금지**: AI가 메일 내용을 예쁘게 써줄 수는 있지만, 사용자가 화면에서 직접 [보내기] 버튼을 누르기 전에는 절대로 혼자 발송하지 않습니다.
2. **묻지도 않고 파일 지우기 금지**: 파일 정리나 디스크 청소를 할 때도 "이 파일을 정말 지울까요?" 하고 화면에 확인창을 띄워 허락을 받습니다.
3. **회사 밖으로 자료 보내기 금지**: 모든 업무 자료와 대화는 내 컴퓨터 안에만 남고, 허락 없이 외부 인터넷 서버로 전송되지 않습니다.

---

## 2. 만드는 방식과 기술 (아주 쉬운 설명)

### ① AI 두뇌 (새로 돈 내지 않음)
- 추가로 비싼 유료 개발자 키(API 키)를 구매할 필요가 없습니다.
- 현재 내 컴퓨터에 이미 로그인되어 있는 **Claude Code, Google Antigravity, 또는 GPT**를 산초가 뒤에서 그대로 심부름꾼처럼 불러와서 답변을 받습니다.

### ② 서버 (추가 설치 프로그램 0개)
- 복잡한 외부 라이브러리나 패키지를 일절 깔지 않습니다. (`npm install` 불필요)
- 오직 컴퓨터에 이미 깔려 있는 **순수 Node.js의 기본 내장 도구**만 사용합니다:
  - `http`: 웹 화면을 브라우저에 띄워주고 대화 내용을 주고받는 통신 도구
  - `fs`: 내 컴퓨터 폴더에 파일을 읽고 쓰는 도구
  - `crypto`: 비밀번호를 안전하게 암호화하고 로그인 상태를 지켜주는 자물쇠 도구
  - `child_process`: 컴퓨터 안의 AI 도구를 뒤에서 대신 실행해 주는 도구

### ③ 데이터 보관 (데이터베이스 서버 없음)
- 오라클이나 MySQL 같은 무거운 데이터베이스 프로그램을 깔지 않습니다.
- 모든 기록(일정, 일감, 설정 등)은 이 폴더 안의 [`data/`](file:///c:/Users/USER/Downloads/Sancho-Test/data/) 폴더에 **JSON(일반 텍스트 데이터)과 Markdown(문서 서식)** 파일로 얌전하게 저장됩니다.
- 이미 깃허브에 올라가지 않도록 설정(`.gitignore`)해 두었으므로, 개인 대화나 사생활 내용이 인터넷(GitHub)에 절대 올라가지 않습니다.

## 3. 화면 구성 (어떻게 생겼나?)

브라우저로 접속하면 한눈에 업무를 볼 수 있는 깔끔한 2단 화면입니다:

### 1) 왼쪽 메뉴 목록 (총 13개)
1. **대시보드**: 오늘 하루 업무 전체 요약 및 AI 비서 홈
2. **일정**: 달력과 시간표, 해야 할 일 마감일 알림
3. **프로젝트**: 진행 중인 큰 일들의 묶음과 상태
4. **WBS (작업분할구조도)**: 큰 일을 작은 조각 일감으로 쪼개서 한눈에 보는 진행표
5. **메일**: 보낼 메일 초안 작성 및 받은 메일 요약
6. **메신저**: 단체방이나 동료에게 보낼 공손한 답변 문구 만들기
7. **회의록**: 회의 대화 내용을 넣으면 3줄 요약과 해야 할 일(할 일 목록) 추출
8. **결재**: 회사 품의서나 기안서 양식을 자동으로 채워주는 공간
9. **목표**: 이번 달, 이번 분기에 달성할 핵심 목표 진행률
10. **공수 (일한 시간 계산)**: 어떤 업무에 몇 시간을 썼는지 적고 불필요하게 낭비된 시간 찾기
11. **지식노트**: 업무 노하우, 업무 매뉴얼, 링크를 모아두는 지식 보관소
12. **워크플로 (업무 순서도)**: 매일 반복하는 작업들을 버튼 하나로 차례대로 실행하기
13. **설정**: 로그인 비밀번호 변경, 화면 색상(다크모드), AI 두뇌 선택

### 2) 중앙 핵심 화면 (대시보드 + AI 채팅)
- 화면 한가운데에 **AI 채팅창**이 항상 열려 있습니다.
- "산초야, 오늘 일정 브리핑해 줘", "어제 회의록 요약해 줘", "연산 작업 돌아가는지 확인해 줘"라고 말하면 산초가 척척 도와줍니다.
- 상단에는 오늘 남은 일감과 중요한 알림이 카드 형태로 표시됩니다.
